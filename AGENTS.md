# OSINT Dashboard V2 — Project Rules

- This is a completely separate new project.
- The existing ~/osint-dashboard project is reference-only.
- You may inspect existing source files and API routes, but NEVER edit files in the original project.
- Never modify, delete, migrate, reset, truncate, or overwrite the existing database.
- Never change OpenCode, Ollama, Grok configuration, or installed tools.
- Do not install dependencies without asking first.
- Do not run live OSINT searches or scans.
- Do not submit real email addresses, phone numbers, usernames, or personal identifiers.
- Build a clean, simplified dashboard with understandable labels and visual results.
- Use existing backend GET endpoints in read-only mode.
- All new files and changes must remain inside ~/osint-dashboard-v2.
- Before editing, inspect the existing project and present a plan for approval.
